> ### АНТИВИРУСНЫЕ СРАБАТЫВАНИЯ
>
> Антивирус может отреагировать на WinDivert.  
> Этот инструмент перехватывает и фильтрует трафик и нужен для работы zapret.
> WinDivert способен использоваться как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские средства. В результате файл удаляется и отправляется в карантин. Название обнаружения обязательно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. Например, Kaspersky предлагает параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете настройку исключений, лучше добавить исключение; при отсутствии уверенности рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` — провайдер Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS в параметрах самой ОС — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках пункт "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/storagebuilderhem/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллических букв и специальных символов

5. Запустите подходящий файл
    * Для поиска работающей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для включения автозапуска: **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние (включено/выключено) отображается в скобках.
  - **`IPSet Filter`** — включить или отключить обработку сервисов из `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret открывается, а с ним — нет.  
  В скобках выводится текущий режим:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP сопоставляется со списком
    - `any` — фильтр применяется к любому IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить применяемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы
  - **`Run Tests`** — открыть инструмент проверки стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неполадки

### После запуска `general*` ничего не изменилось

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), видимый на панели задач.  
Если процесса нет, ознакомьтесь с [#522](https://github.com/storagebuilderhem/zapret-discord-youtube/issues/522)

### Рабочей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - В появившемся каталоге откройте файл `hosts` через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированное в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что hosts действительно был сохранён.

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/storagebuilderhem/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Стратегия не обязательно будет работать постоянно.**
> Вариант, который некоторое время обходил блокировку, позднее может перестать работать после его обнаружения.
> Здесь собрано много разных стратегий. Если ни одна не дала результата, создайте новую на основе существующей, изменив её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте наличие ошибок

- Проверьте, добавлен ли адрес ресурса в доменные или IP-списки

- Последовательно испытайте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/storagebuilderhem/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сначала сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Затем выполните `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/storagebuilderhem/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву, откройте свойства и, если внизу справа есть пункт разблокировки, отметьте его, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска, исключив пробелы и специальные символы из пути
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующий
- После нахождения подходящей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> выберите стратегию

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на неожиданные для вас ресурсы.

### Античит обнаруживает WinDivert

- Инструкция размещена здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените в [`bin`](./bin) файлы `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё присутствует среди служб

1. В командной строке Windows (Win+R, `cmd`) найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Испытайте остальные стратегии, особенно если выбранная раньше перестала работать.
- Также смотрите [#251](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- Выполните `service.bat` -> `Run Diagnostics`, затем очистите там кэш Discord
- Проверьте приложение Discord и выясните, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не работает и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- Дополнительные сведения: [#252](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/storagebuilderhem/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры или нет подключения

Игр много, поэтому проверить и исправить каждую из них невозможно.

Наиболее универсальный порядок действий:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не сработало, дополнительно попробуйте режим `ipset any`

Учтите: `ipset any` может нарушить открытие большого количества сайтов. Не оставляйте этот режим включённым постоянно. Лучше определить все IP-адреса, которые использует игра, и добавить их в `ipset-all.txt`

Если результата нет и после этого, создайте обсуждение в разделе [Discussions](https://github.com/storagebuilderhem/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблема не перечислена

- Оформите её [здесь](https://github.com/storagebuilderhem/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены будут учитываться автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
